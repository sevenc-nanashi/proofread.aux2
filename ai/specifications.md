# 仕様書

AIによる校正を行うプラグイン。

## 仕様

- UIはsevenc-nanashi/quantizer.aux2を参考にする。
- プラグインの実装方法などはsevenc-nanashi/aviutl2-rsを参考にする。

## ユーザーの流れ

### 初回セットアップ

1. ユーザーはプラグインをインストールする。
2. プラグインを初めて起動すると、OpenAI API compatなエンドポイントとモデルとAPIキーの入力を求められる。

- この時、いくつかプリセットを用意しておく。具体的には、「ChatGPT」「Gemini」「Claude」「OpenRouter」など。
  - プリセットが選択された場合、エンドポイントとモデルは自動的に入力される。また、APIキーの発行方法へのリンクも表示される。
  - APIキーの発行やユーザー層を考慮して、Geminiをデフォルトのプリセットにする。

3. ユーザーは必要な情報を入力し、保存する。

### マーカーの設置

マーカーは何もしないフィルタプラグインとして実装する。
以下のマーカーが使用される：

- `校正対象（レイヤー、テキスト）@proofread.aux2`
- `校正対象（単一、テキスト）@proofread.aux2`
- `校正対象（レイヤー、音声）@proofread.aux2`
- `校正対象（単一、音声）@proofread.aux2`
- `校正メモ@proofread.aux2`

- 「校正対象」は、校正の対象となるテキストや音声を指定するためのマーカー。
  - パラメーターはなし。
  - （レイヤー）はas_object: trueなフィルタで、これが置かれているレイヤー全体が校正の対象となる。
  - （単一）はas_object: falseなフィルタで、これが置かれているテキストや音声のみが校正の対象となる。
- 「校正メモ」は、校正の際にAIに提供する追加情報を指定するためのマーカー。
  - as_object: falseなフィルタで、これが置かれているテキストがAIに付随情報として提供される。
  - パラメーターは「内容」のみ。
  - 例えば、「このテキストは意図的に誤字がある」など。

### 校正の使用

UI：

```
proofread.aux2  <設定>
----------------------

<校正を開始>

プロンプト：
[ テキストエリア ]
```

1. まずプロジェクト単位でプロンプトを設定する。
   - 「どのような動画か」「どのような視聴者か」など。

2. 「校正を開始」ボタンを押すと、ユーザーが設定したテキストとプロジェクトの情報がAIに送信される。

- プロジェクト全体を走査し、マーカーによって指定されたテキストや音声を収集する。

- テキストは書かれているテキスト、音声は文字起こしされたテキストとしてAIに送信する。
  - 音声はwhisper-rsを用いて文字起こしする。精度の高いモデルを使用するが、完璧ではないことをユーザーに伝える。
- 以下のようなプロンプトをAIに送信する：

````
あなたは動画の校正者です。以下の情報をもとに、動画のテキストと音声を校正してください。
出力は以下のフォーマットを用いてください：
```json
{
    "all": "全体の指摘・コメント",
    "details": [
        {
            "id": "テキストや音声のID",
            "priority": "指摘の優先度（'low', 'medium', 'high'のいずれか）",
            "comment": "個別の指摘・コメント"
        }
    ]
}
```

# 注意
- テキストの色は校正の際に重要な情報となります。例えば、しゃべっているキャラクターを区別するために色分けされている場合があります。
- 音声の文字起こしには誤りが含まれている可能性があります。

# プロジェクトの情報
{プロジェクトの情報}

# 校正対象のテキストと音声
## {ID}
種別：テキスト
色：{テキストの色}
レイヤー：{テキストが置かれているレイヤーの名前}
開始時間：{テキストの開始時間}
内容：
{テキスト}
メモ：
{校正メモの内容（もしあれば）}

## {ID}
種別：音声
レイヤー：{音声が置かれているレイヤーの名前}
開始時間：{音声の開始時間}
文字起こしされた内容：
{文字起こし}
メモ：
{校正メモの内容（もしあれば）}
````

3. AIからの応答を受け取ったら、ユーザーに表示する。

UI：
```
proofread.aux2
----------------------

<戻る>

+ --------------------- +
| 全体の指摘・コメント |
| [ テキストエリア ]    |
+ --------------------- +

+----------------------------------------+
| 位置：{IDから得たテキストや音声の位置} |
| 種別：{テキストか音声か}               |
| 優先度：{低・中・高}                   |
| <ジャンプ>  <メモを追加>               |
| -------------------------------------- +
| [ 個別の指摘・コメント ]               |
+----------------------------------------+
```

UIについてはquantizer.aux2をを参考にしてください。

- 「<ジャンプ>」を押すと、該当のテキストや音声の位置にタイムラインが移動する。
- 「<メモを追加>」を押すと、該当のテキストや音声に「校正メモ」マーカーが追加される。内容はユーザーが入力する。

4. ユーザーはAIからの指摘を確認し、必要に応じてテキストや音声を修正する。
5. ユーザーはAIからの指摘をもとに、動画の品質を向上させることができる。

## 注意点

- AIの指摘はあくまで提案であり、必ずしも正しいわけではないことをユーザーに伝える。
- クレデンシャルは`$LOCALAPPDATA/proofread.aux2/credentials.json`に保存する。セキュリティに注意すること。
