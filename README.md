# proofread.aux2

[![AviUtl2 Catalog](https://img.shields.io/endpoint?url=https%3A%2F%2Faviutl2-catalog-badge.sevenc7c.workers.dev%2Fapi%2Fbadge%2Fsevenc-nanashi.proofread-aux2)](https://aviutl2-catalog-badge.sevenc7c.workers.dev/package/sevenc-nanashi.proofread-aux2)

AIによる校正を行うプラグイン。

## 使い方

> [!WARNING]
> 工事中...

校正対象は「校正対象（レイヤー）@proofread.aux2」「校正対象（単一）@proofread.aux2」で指定されたレイヤーまたはオブジェクトのテキストです。
テキストは「テキスト」という名前の設定項目が対象となります。
同時に文字色、レイヤー名、PSDToolkitのキャラクターIDも送信されます。
プロンプトは`./src/prompts/default.hbs`を参照してください。

## インストール

[Releases](https://github.com/sevenc-nanashi/proofread.aux2/releases/latest)から`sevenc-nanashi.proofread-aux2-v<バージョン>.au2pkg.zip`をダウンロードし、AviUtl2のプレビューにドラッグ&ドロップしてください。
